# AI Voice Input 开发步骤

## 阶段 1：项目骨架

1. 初始化 Electron、Vite、React 项目。
2. 配置主进程、预加载脚本、渲染进程目录。
3. 配置 `electron-builder` 输出 macOS DMG。

## 阶段 2：后台能力

1. 实现单实例锁。
2. 实现主窗口关闭隐藏。
3. 实现托盘图标和菜单。
4. 实现状态浮窗。

## 阶段 3：配置与 IPC

1. 实现本地配置读写。
2. 暴露安全 preload API。
3. 渲染进程加载和保存设置。
4. 主进程广播状态变化。

## 阶段 4：权限

1. 实现麦克风权限检测和请求。
2. 实现辅助功能权限检测和系统设置跳转。
3. 实现通知能力检测。
4. 实现权限页。

## 阶段 5：快捷键

1. 注册默认语音输入快捷键。
2. 注册默认语音问答快捷键。
3. 支持快捷键录入和冲突检测。
4. 修改后自动保存并立即生效。

## 阶段 6：语音链路

1. 创建隐藏录音窗口。
2. 使用 `getUserMedia` 和 `MediaRecorder` 录音。
3. 接入转写服务接口。
4. 添加失败兜底和状态提示。

## 阶段 7：模型与投递

1. 实现 DeepSeek V4 和 GLM-5.1 预设。
2. 实现连接测试。
3. 实现润色和问答调用。
4. 实现剪贴板兜底和自动粘贴尝试。

## 阶段 8：页面

1. 首页展示就绪状态和关键配置。
2. 快捷键页展示注册状态和修改入口。
3. 模型页支持预设、凭证和连接测试。
4. 语音页支持语言、模式和高级配置。
5. 提示词页支持编辑和恢复默认。
6. 词库页支持词条增删启停。
7. 权限页支持打开设置和重新检测。

## 阶段 9：验证与打包

1. 运行静态构建。
2. 启动 Electron 验证窗口和主流程。
3. 生成 DMG 安装包。
4. 记录产物路径和已知限制。
